# 给你的一封小小告白

一个适合手机打开的互动式表白网页。

## 打开方式

直接双击 `index.html` 即可打开，无需安装依赖、无需联网。

## 文件说明

- `index.html`：页面结构与内嵌猫咪 SVG
- `style.css`：粉色视觉风格、手机适配、按钮与礼物盒动画
- `script.js`：拒绝互动、表情切换、成功转场、礼物盒和惊喜页面逻辑

## 互动流程

1. 打开页面，显示“可以让我成为你的女朋友吗？”
2. 点击“不可以”，猫咪表情变化，“可以”按钮逐渐变大
3. 点击“可以”，进入成功页面
4. 点击礼物盒，播放打开动画
5. 显示“获得惊喜礼物一份”和专属文字
